Status: DONE (stratified 512-tile subset)

Branch: j/t01-t07-core

## What works

- Frozen `facebook/dinov2-small` (ViT-S/14) CLS embeddings.
- Input size 224.
- Train/val/test embeddings saved in split order.
- Metadata saved with model name, input size, embedding dimension, and split sizes.

## Artifacts

- `artifacts/embeddings/dinov2_train.npy` — `(512, 384)`
- `artifacts/embeddings/dinov2_val.npy` — `(512, 384)`
- `artifacts/embeddings/dinov2_test.npy` — `(512, 384)`
- `artifacts/embeddings/dinov2_meta.json`

## Acceptance

- Shape `(N, 384)`.
- No NaNs.
- Order matches split JSON.
- Model name and input size saved.
- `orthogonality` sanity passes after alignment.

## How to run

```sh
python scripts/extract_embeddings.py --limit 512
```

## Known issues

- Full 27k extraction was started but stopped on CPU because it was too slow for the phase gate.
- The pipeline supports the full split; rerun without `--limit` on a GPU.
- N=512 is a stratified subset, not the full test set. Report this honestly.
