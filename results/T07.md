## Important metric distinction

There are two different tasks:

1. **Text→image search:** each of the 50 captions is a query. Top-1 = the top image has the caption's class. N = 50 queries.
2. **Image→class:** classify each of the 4,050 test images by its nearest class caption. N = 4,050 images. This is the number comparable with ResNet-18 accuracy.

Do not compare the 50-query search number with per-image ResNet accuracy.

## 1. Text→image search — full test split

| Method | Top-1 | Top-5 | Queries |
|---|---:|---:|---:|
| Procrustes | 0.96 | 1.00 | 50 |
| Random rotation | 0.18 | 0.34 | 50 |
| Unaligned cosine | 0.10 | 0.34 | 50 |

Source: A re-ran J's unchanged scripts on the full split on MPS. J's CPU smoke run used 512 tiles and is retained in `retrieval_val.csv`.

## 2. Image→class — 4,050 test images

| Method | Accuracy | Top-5 | Macro-F1 |
|---|---:|---:|---:|
| ResNet-18 (supervised) | 0.9817 | — | 0.9812 |
| Procrustes | 0.8121 | 0.9901 | 0.7948 |
| Random rotation | 0.1590 | 0.6588 | 0.1559 |
| Unaligned cosine | 0.0827 | 0.5326 | 0.0720 |
| Majority class | 0.1111 | — | 0.0200 |

This is the comparable table. Procrustes is well above the null baselines but below supervised ResNet-18.

## Acceptance

- Text search top-1/top-5 reported with N = 50 queries.
- Image→class accuracy and macro-F1 reported with N = 4,050 images.
- Random rotation and unaligned baselines reported for both tasks.
- Test split untouched by fitting.
- No tuning on test.
- No zero-shot claim: the rotation is fitted on labelled image–caption pairs.

## How to run

Full split (GPU/MPS):

```sh
python scripts/extract_embeddings.py
python scripts/fit_alignment.py
python scripts/evaluate_retrieval.py
python -m src.evaluate caption-classification --split test
```

CPU smoke (J):

```sh
python scripts/extract_embeddings.py --limit 512
python scripts/fit_alignment.py --limit 512
python scripts/evaluate_retrieval.py --limit 512
```
