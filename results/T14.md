## Observations for the write-up (live demo; not logged runs)

- Upper Arlington search: `river corridor` → ua_049, ua_041, ua_045, all River, even though image→label calls
  6/10 of these tiles Highway. Search ranks *relative* similarity, so it can still find them.
- Upper Arlington search: `commercial area` and `park or grassland` mostly return wrong tiles; scores are low
  (0.16–0.32).
- `climate change` → scores ≈ 0.05. The tool returns tiles anyway (no abstention).

## How to run

    pip install -r requirements.txt
    python scripts/prepare_data.py
    python scripts/extract_embeddings.py --device mps   # or cuda; CPU is very slow on the full split
    python scripts/fit_alignment.py
    python app.py --prefetch                            # once, online
    python app.py                                       # http://127.0.0.1:7860
