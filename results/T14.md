Phase 1 update:
- Added `RealBackend`. It loads `procrustes.npz`, `dinov2_test.npy`, `minilm_captions.npy`,
  `minilm_caption_index.json`, and `data/splits/test.json`. It switches on automatically when all of them exist;
  otherwise the app falls back to MOCK and prints which files are missing. `--mock` forces mock mode.
- Text search ranks the EuroSAT test gallery by cosine similarity to the query. Upload classification compares
  the tile to per-class caption centroids.
- Uses `src.alignment.transform_images/transform_texts` when importable, so the demo matches T06 exactly.
- If an encoder can't load (for example, no internet and the model isn't cached), the UI shows an error message
  instead of crashing.
- Tested with synthetic artifacts that follow INTERFACES.md §4: all 10 class queries returned only their own
  class, the upload returned the correct class, the metrics table filled from the CSVs, and the UI built in REAL mode.
Metrics:
- none (mock only; the UI shows "—" until artifacts/metrics/*.csv exist)

What works:
- Three tabs: Text search (top-3 gallery + scores), Classify a tile (upload → top-3 labels),
  Results & limits (baseline table + failure example).
- Prototype disclaimer, a visible MOCK banner, and out-of-distribution warning on uploads.
- Placeholder tiles are generated in code; no images or internet needed.
- The baseline table already reads `majority.csv`, `resnet18.csv`, `retrieval.csv` from
  `artifacts/metrics/` using the column names in `plan/INTERFACES.md` and shows "—" when they are missing.
- Planned failure (`permanent crop` → AnnualCrop) is reproduced in mock mode for rehearsal.
