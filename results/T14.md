## What works

- **REAL mode** turns on automatically when J's artifacts exist. Startup prints:
  `[demo] REAL mode — gallery N=512 of 4050 EuroSAT test tiles`.
- All math goes through J's code: `src.alignment` (load_procrustes, transforms), `src.encoders`
  (load_dinov2, extract_image_embeddings, load_minilm, encode_texts), `src.data.get_transforms`.
  The demo's fresh encoding of a test tile equals the saved `dinov2_test.npy` row (cosine 1.0).
- Text search over the 512-tile test gallery. Upload → nearest class (caption centroids, image→text).
- Baseline table reads `retrieval.csv` (J's `n_images` column) and `majority.json`.
  It explains that the rows measure different things on different N.
- "Where it fails" runs `climate change` and `permanent crop` live through the model, so no hand-picked or
  false claims.
- Runs offline once models are cached: `python app.py --prefetch` (while online), then
  `HF_HUB_OFFLINE=1 python app.py`.
- `--mock` still gives the placeholder UI when no artifacts exist.
