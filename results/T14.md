## What works

- **REAL mode** turns on automatically when J's artifacts exist. Startup prints:
  `[demo] REAL mode — gallery N=512 of 4050, transforms from src.alignment`.
- All math goes through J's code: `src.alignment` (`load_procrustes`, transforms), `src.encoders`
  (`load_dinov2`, `extract_image_embeddings`, `load_minilm`, `encode_texts`), `src.data.get_transforms`.
- Text search over the 512-tile test gallery.
- Upload → nearest class using caption centroids.
- Baseline table reads `caption_classification_test.csv` for image→class, `retrieval.csv` for text search, `majority.csv`/`majority.json`, and `resnet18.csv`.
- "Where it fails" runs `climate change` and `permanent crop` live through the model, so the demo never claims a failure the model did not make.
- Runs offline once models are cached:
  `python app.py --prefetch` once online, then `HF_HUB_OFFLINE=1 python app.py`.
- `--mock` still gives the placeholder UI when no artifacts exist.

## Checked

- Reproduced J's 512-tile T07 smoke run: Procrustes 0.94/0.96, random 0.10/0.32, unaligned 0.16/0.36. Full-split metrics are in `results/T07.md`.

## How to run

```sh
pip install -r requirements.txt
python app.py --prefetch        # once, online
python app.py                   # real mode
# http://127.0.0.1:7860
```

If artifacts are missing:

```sh
python scripts/prepare_data.py
python scripts/extract_embeddings.py --limit 512
python scripts/fit_alignment.py --limit 512
python scripts/evaluate_retrieval.py --limit 512
```
