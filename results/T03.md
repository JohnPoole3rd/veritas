# T03 — Caption templates

Status: DONE
Owner: J
Branch: j/t01-t07-core

## What works

- Five caption templates for each of the 10 EuroSAT classes.
- Caption records saved as JSONL with caption ID, label, text, and template ID.
- Helper to group captions by label and sample one per tile.

## Artifacts

- `data/captions.jsonl` — 50 captions
- `src/captions.py`

## Acceptance

- Every class has at least 5 captions.
- Captions are class-consistent.
- No caption mentions another class.

## How to run

```sh
python scripts/prepare_data.py
```
