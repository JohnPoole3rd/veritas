# T02 — EuroSAT loader and splits

Status: DONE
Owner: J1 (subagent of J)
Branch: j/t01-t07-core

## What works

- EuroSAT loads through `torchvision.datasets.EuroSAT`.
- Stratified 70/15/15 split.
- Items are shuffled so small debug subsets are not class-ordered.
- Split JSON files saved with tile IDs, relative paths, and labels.

## Artifacts

- `data/splits/train.json` — 18,900 items
- `data/splits/val.json` — 4,050 items
- `data/splits/test.json` — 4,050 items
- `data/raw/eurosat/` — downloaded RGB tiles

## Acceptance

- 27,000 tiles loaded.
- 10 classes.
- Stratified split.
- No duplicate tile IDs across splits.
- Test split untouched.

## How to run

```sh
python scripts/prepare_data.py
```

## Known issues

- Raw data is not committed; it is reproducible from torchvision.
- DINOv2 sees 64×64 EuroSAT tiles upscaled to 224; this is a documented limitation.
