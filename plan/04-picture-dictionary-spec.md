# Archived Alternative — Platonic Picture Dictionary

**Status:** Not selected. Do not build this for the current submission.

This file is kept only as a record of the alternative considered for the AI + Languages track.

## Summary

A multimodal vocabulary explorer that links a word in a learner’s language to images and pronunciation in a target language. It would align frozen DINOv2 image embeddings with a multilingual text encoder (LaBSE or multilingual MiniLM) using Procrustes, then retrieve images for a word.

## Why it was not selected

- Requires accurate translations and a speaker of the target language.
- Multilingual text-encoder coverage is uncertain for low-resource languages.
- Audio and user testing add time.
- Less certain technical result in 48 hours.
- The team selected the Climate project instead.
